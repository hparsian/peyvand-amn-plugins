# راهنمای کاربر — داشبورد یکپارچه درمانگر

## ورود

پس از فعال‌سازی، منوی «داشبورد یکپارچه» در پیشخوان وردپرس ظاهر می‌شود.
دسترسی زمانی فعال است که کاربر یکی از این‌ها باشد:

* مدیر سایت (`manage_options`)
* دارای کپابیلیتی `pas_dashboard_access`
* دارای کپابیلیتی `pas_manage_case_files` (درمانگر)

دیدن داده‌های بالینی (پرونده و یادداشت) به `pas_manage_case_files` یا
`manage_options` نیاز دارد. دیدن پرونده‌ی همه‌ی درمانگرها به
`pas_view_all_case_files` نیاز دارد.

## ماژول‌ها

| ماژول | کار |
|---|---|
| نمای کلی | تعداد پرونده‌های مجاز، جلسه‌های پیش‌رو، وضعیت اکوسیستم |
| مراجعان | جست‌وجو با شناسه‌ی یکتا/موبایل/ایمیل و مشاهده‌ی شناسه‌ها |
| پرونده‌ها | فهرست پرونده‌های شما، جزئیات، یادداشت جلسه، نمای زوجی |
| آزمون‌ها | فهرست آزمون‌های موجود |
| نوبت‌ها | جلسه‌ی بعدی و نوبت‌های پنل مراجعان (فقط‌خواندنی) |
| گزارش‌ها | آمار و خروجی CSV حداقلی |
| ارتباطات | وضعیت پل پیامک، لاگ ارسال، آمادگی یادآور |
| اعلان‌ها | یادآور جلسه‌های پیش‌رو، خوانده/نخوانده |
| سلامت سیستم | بررسی نسخه‌ها، وابستگی‌ها و رمزنگاری |
| تنظیمات | تعداد ردیف، اعلان‌ها، فعال‌بودن یادداشت |
| ممیزی | رخدادهای داشبورد (فقط مدیر) |

## ثبت یادداشت جلسه

1. پرونده را باز کنید.
2. اگر کلید رمزنگاری تنظیم نشده باشد، پیام هشدار می‌بینید و فرم نمایش داده نمی‌شود.
3. تاریخ جلسه (میلادی)، شماره‌ی جلسه و متن را وارد کنید.
4. «ثبت یادداشت» را بزنید.

حذف یادداشت، نسخه‌ی قبلی را در تاریخچه نگه می‌دارد؛ از همان بخش می‌توانید
نسخه را بازگردانی کنید.

## نمایش پارتنر

اگر پرونده پارتنر داشته باشد اما دسترسی شما به پرونده‌ی پارتنر تأیید نشده
باشد، فقط پیام «دسترسی تأیید نشده» نمایش داده می‌شود؛ هیچ نام، شماره یا
جلسه‌ای از پارتنر نشان داده نمی‌شود.

## خروجی CSV

در ماژول گزارش‌ها، دکمه‌ی «دریافت CSV». خروجی شامل شناسه، وضعیت، درمانگر،
تاریخ آخرین جلسه و آخرین به‌روزرسانی است؛ نام و شماره‌ی مراجع در آن نیست.

## کارهایی که این داشبورد انجام نمی‌دهد

* ارسال پیامک
* ساخت/ویرایش نوبت
* نمایش نتیجه و نمره‌ی آزمون‌ها
* ساخت یا حذف پرونده
* تغییر تنظیمات افزونه‌های دیگر

برای این کارها از صفحه‌های همان افزونه‌ها استفاده کنید.

## عیب‌یابی سریع

| نشانه | علت احتمالی |
|---|---|
| «کلید رمزنگاری تنظیم نشده» | `PAS_CORE_ENCRYPTION_KEY` در `wp-config.php` نیست |
| «افزونه‌ی پرونده‌ها فعال نیست» | `pivand-amn-case-file` غیرفعال است |
| فهرست پرونده خالی | پرونده‌ای به شما تخصیص داده نشده |
| منو دیده نمی‌شود | کاربر کپابیلیتی لازم را ندارد |
