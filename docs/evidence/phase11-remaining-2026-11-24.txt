شاهد خام سه اسکریپت باقی‌ماندهٔ فاز ۱۱ روی MySQL 8.4 — ۲۰۲۶-۱۱-۲۴
===================================================================

این فایل نتیجهٔ اجرای `encryption.php`، `backup-restore.sh` و
`migration-verify.php` روی همان **بدل MySQL Community Server 8.4.11 / InnoDB**
است که شاهدهای `staging-mysql84-2026-11-24.txt` و
`phase11-http-2026-11-24.txt` از آن آمده‌اند. با این اجرا، هر شش اسکریپت فاز ۱۱
روی این بدل آزموده شده‌اند. لاگ کامل خام در
`phase11-remaining-2026-11-24-raw.txt` (۱۱۴ خط، SHA-256
`2dd65dd9e1dacefe4b54d718698826434b55ba57f3d2713c8467355379cbc307`) کنار همین
فایل است و هیچ خطی از شاهدهای قبلی بازنویسی نشده است.

`note_id=11`) به بدل اضافه کرد.

## ۲) بکاپ و بازیابی — `backup-restore.sh`

اجرا روی دیتابیس خود بدل، با کلاینت‌های رسمی MySQL 8.4 (اسکریپت نام
`mariadb`/`mariadb-dump` می‌خواهد، پس همان باینری‌ها با آن نام در PATH قرار
گرفتند) و کلید رمزنگاری در یک فایل جدا:

```
MYSQL_HOST=127.0.0.1 MYSQL_PORT=3308 MYSQL_USER=root \
WP_PATH=/tmp/br-key PHP_BIN=php DUMP=/tmp/backup-restore84.sql \
bash tests/phase11/backup-restore.sh wp_pas wp_pas_rs
```

نتیجه (exit 0):

| بررسی | نتیجه |
|---|---|
| dump با `--single-transaction --routines --triggers` | `dump_bytes=195185` |
| بازیابی در دیتابیس تازهٔ `wp_pas_rs` | انجام شد |
| فهرست جدول‌ها | `tables_src=39 tables_dst=39 diff=0` |
| شمارش ردیف همهٔ جدول‌ها | `row_count_mismatches=0` |
| CHECKSUM جدول‌های کلیدی | `cases=25621314`، `notes=545201936`، `audit_log=3576831884` — در مبدأ و مقصد یکسان |
| جست‌وجوی متن سادهٔ بالینی در dump | `plaintext_hits=0` |
| رمزگشایی یک ciphertext از دیتابیس بازیابی‌شده | `decrypt_from_restored_db=OK` |
| همان ciphertext بدون کلید | `restore_without_key=cannot_decrypt` |
