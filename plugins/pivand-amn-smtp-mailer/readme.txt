ارسال ایمیل‌های خروجی وردپرس از طریق SMTP واقعی یا Brevo API به‌جای mail() پیش‌فرض هاست.

== Description ==
تمام ایمیل‌های خروجی وردپرس (`wp_mail`) را به‌جای mail() پیش‌فرض هاست، از طریق SMTP واقعی (مثلاً جیمیل یا خود هاست) یا Brevo API ارسال می‌کند تا در اسپم گیر نکنند.

از نسخه‌ی 1.1.4 به بعد، رمز عبور و API Key به‌صورت رمزنگاری‌شده در پایگاه داده ذخیره می‌شوند.

== Requirements ==
* وابسته به افزونه‌ی «پیوند امن — هسته مشترک» برای کلاس `Pas_Core_Crypto`.

== چرا فقط SMTP و Brevo؟ (نسخه‌ی ۱.۵.۰) ==
نسخه‌ی قبلی چهار روش داشت. بعد از بررسی وضعیت واقعی روی هاست‌های ایرانی، Mailgun و SendGrid حذف شدند:

* Mailgun (Sinch) و SendGrid (Twilio) شرکت‌های آمریکایی‌اند و قوانین Export
  Compliance/OFAC را روی حساب‌های مرتبط با ایران اعمال می‌کنند — حتی اگر
  یک‌بار ثبت‌نام موفق شود، ریسک بسته‌شدن حساب وسط کار وجود دارد.
* Brevo شرکتی اروپایی است و به این شکل حساب کاربران ایرانی را محدود
  نمی‌کند، و چون فقط از HTTPS (پورت 443) استفاده می‌کند نه پورت SMTP، حتی
  وقتی هاست پورت 587/465 را می‌بندد هم کار می‌کند.
* اگر «خطای SMTP: نتوانست به میزبان SMTP متصل شود» می‌بینید، معمولاً یعنی
  هاست پورت خروجی SMTP را بسته (رایج در هاست‌های ایرانی برای جلوگیری از
  اسپم) — نه این‌که خودِ جیمیل غیرقابل‌دسترس باشد. با تیکت به هاست برای باز
  کردن پورت 587/465 می‌توان روش SMTP را هم فعال کرد؛ در غیر این‌صورت Brevo
  گزینه‌ی قابل‌اتکاتر است.

== Changelog ==

= 1.5.0 =
* حذف روش‌های Mailgun و SendGrid (دلیل در بخش «چرا فقط SMTP و Brevo؟» بالا توضیح داده شده).
* ساده‌سازی کد: تنظیمات، زنجیره‌ی failover، فرم ادمین و منطق ذخیره‌سازی همگی متناسب با دو روش باقی‌مانده بازنویسی شدند.
* صفحه‌ی تنظیمات حالا توضیح می‌دهد چرا هر روش ممکن است روی هاست ایرانی کار نکند.

= 1.4.0 =
* معماری Failover: زنجیره‌ی SMTP اصلی ← SMTP پشتیبان (اختیاری) ← ارسال بومی هاست (اختیاری، آخرین چاره).
* اگر همه‌ی روش‌ها شکست بخورند، ایمیل در یک صف داخلی ذخیره و با wp_cron و فاصله‌ی زمانی افزایشی (۵ دقیقه تا ۸ ساعت، حداکثر ۵ بار) خودکار دوباره امتحان می‌شود.
* صفحه‌ی جدید ادمین «گزارش ایمیل‌ها»: وضعیت هر ارسال (موفق/در انتظار retry/نهایتاً ناموفق) به‌همراه دکمه‌ی «امتحان دوباره الان».
* رمز SMTP پشتیبان هم مثل رمز اصلی با Pas_Core_Crypto رمزنگاری می‌شود.

= 1.1.4 =
* امنیت: رمز عبور SMTP اکنون هنگام ذخیره با `Pas_Core_Crypto::wrap_encrypted` رمزنگاری و هنگام استفاده decrypt می‌شود.
* سازگاری با نسخه‌های قبلی: مقادیر قدیمی رمزنگاری‌نشده همچنان بدون مشکل کار می‌کنند تا زمانی که تنظیمات دوباره ذخیره شود.

= 1.1.3 =
* نسخه‌ی پیشین (بدون رمزنگاری رمز عبور SMTP).

== Upgrade Notice ==

= 1.5.0 =
اگر «روش ارسال» قبلاً روی Mailgun یا SendGrid تنظیم شده بود، افزونه بعد از آپدیت به‌صورت خودکار به SMTP برمی‌گردد (تا ایمیلی گم نشود)، ولی چون تنظیمات SMTP احتمالاً کامل نیست، لطفاً یک‌بار وارد صفحه‌ی تنظیمات شوید و روش Brevo را انتخاب و API Key آن را وارد کنید (توصیه‌شده برای هاست ایرانی).
