# فایل‌های فونت Vazirmatn — باید دستی اضافه شوند

من (Claude) به اینترنت دسترسی نداشتم که فایل‌های باینری فونت رو خودم دانلود
کنم، پس فقط زیرساخت (CSS + کلاس PHP) رو ساختم. برای تکمیل کار، ۴ فایل زیر
رو باید دقیقاً با همین نام‌ها کنار همین فایل (`assets/fonts/vazirmatn/`)
آپلود کنی:

- `Vazirmatn-Regular.woff2`   (وزن ۴۰۰)
- `Vazirmatn-Medium.woff2`    (وزن ۵۰۰)
- `Vazirmatn-SemiBold.woff2`  (وزن ۶۰۰)
- `Vazirmatn-Bold.woff2`      (وزن ۷۰۰)

## از کجا بگیرم؟

منبع رسمی و معتبر فونت Vazirmatn، مخزن گیت‌هاب سازنده‌ست:
https://github.com/rastikerdar/vazirmatn/releases

از آخرین ریلیز، پوشه‌ی `webfonts/woff2/` رو باز کن و ۴ فایل بالا رو از اونجا
بردار (اسم فایل‌ها توی ریلیز رسمی دقیقاً همینه: Regular/Medium/SemiBold/Bold).
لایسنس این فونت SIL Open Font License هست — برای استفاده‌ی تجاری روی سایت
مشکلی نداره.

## بعد از آپلود چیکار کنم؟

هیچی — همین که فایل‌ها با این اسم‌ها کنار `vazirmatn.css` باشن، خودکار کار
می‌کنه. هر پلاگینی که `Pas_Core_Fonts::enqueue()` رو صدا بزنه (یا از
`Pas_Core_Fonts::handle()` به‌عنوان dependency استفاده کنه) فونت رو از همین
مسیر لود می‌کنه، نه از گوگل.

## تست سریع

بعد از آپلود، توی مرورگر Network tab سایت رو باز کن و مطمئن شو که دیگه
هیچ درخواستی به `fonts.googleapis.com` یا `fonts.gstatic.com` نمی‌ره (بعد
از این‌که سه پلاگین مصرف‌کننده هم به‌روزرسانی بشن — قدم بعدی).
