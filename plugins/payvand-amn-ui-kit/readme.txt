== توضیح ==

این افزونه کتابخانه است: توکن‌های برند، فونت وزیرمتن سلف‌هاست، کامپوننت‌های
RTL و حالت تاریک اختیاری را در اختیار بقیهٔ افزونه‌های خانواده می‌گذارد.

هیچ استایل یا اسکریپتی به‌صورت خودکار بارگذاری نمی‌شود. افزونهٔ مصرف‌کننده
باید صریحاً یکی از این‌ها را صدا بزند:

    PUI::enqueue('auth');        // صفحهٔ ورود
    PUI::enqueue('panel');       // پنل مراجع
    PUI::enqueue('admin');       // صفحات پیشخوان
    PUI::enqueue_shell('panel'); // + پوستهٔ تمام‌صفحه

اگر این افزونه غیرفعال باشد، افزونه‌های مصرف‌کننده باید با
`class_exists('PUI')` / `function_exists('pui_card_open')` گارد بزنند و به
CSS فعلی خودشان برگردند.

== پیش‌نمایش ==

پیشخوان → ابزارها → «کیت رابط کاربری». شامل پالت، تایپوگرافی، آیکون‌ها،
همهٔ کامپوننت‌ها و طرح اولیهٔ چهار محیط (ورود، پنل مراجع، داشبورد درمانگر،
مرکز مدیریت).
