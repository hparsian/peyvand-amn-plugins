احراز هویت دومرحله‌ای (TOTP) به‌همراه کدهای پشتیبان برای ورود ادمین‌های اکوسیستم پیوند امن.

== Description ==
احراز هویت دومرحله‌ای (TOTP، سازگار با Google Authenticator/Authy) برای ورود به پیشخوان — مخصوص ادمین‌هایی که به داده‌های حساس (پرونده مراجعین، تنظیمات پرداخت/پیامک) دسترسی دارند.

از نسخه‌ی 1.3.0 امکان تولید کدهای پشتیبان یک‌بارمصرف نیز اضافه شده، برای مواقعی که دستگاه احراز هویت کاربر در دسترس نیست.

== Requirements ==
* وابسته به افزونه‌ی «پیوند امن — هسته مشترک» برای کلاس `Pas_Core_Crypto`.
