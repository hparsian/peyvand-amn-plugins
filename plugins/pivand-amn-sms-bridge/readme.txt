تنها نقطه‌ی اتصال به وب‌سرویس ملی‌پیامک برای کل اکوسیستم پیوند امن.

== Description ==
این افزونه تنها نقطه‌ی اتصال واقعی به وب‌سرویس ملی‌پیامک برای کل اکوسیستم پلاگین‌های پیوند امن است. هیچ پلاگین دیگری مستقیماً به ملی‌پیامک وصل نمی‌شود؛ همه از طریق فیلتر مشترک `pas_send_sms` درخواست ارسال می‌دهند.

از نسخه‌ی 1.1.2 به بعد، کلید API ملی‌پیامک به‌صورت رمزنگاری‌شده در پایگاه داده ذخیره می‌شود.

== Requirements ==
* وابسته به افزونه‌ی «پیوند امن — هسته مشترک» برای کلاس `Pas_Core_Crypto`.
