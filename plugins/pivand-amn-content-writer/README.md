# ACO Content Writer — راهنمای نصب و استفاده

## نصب

1. پوشه `aco-content-writer` را زیپ کنید
2. در وردپرس به **افزونه‌ها ← افزودن افزونه ← بارگذاری** بروید
3. فایل ZIP را آپلود و فعال کنید

---

## دریافت کلید API رایگان

### گزینه ۱ — OpenRouter (توصیه شده)
1. به [openrouter.ai](https://openrouter.ai) بروید
2. با ایمیل ثبت‌نام کنید
3. به بخش **Keys** بروید و یک کلید بسازید
4. مدل‌های رایگان با `(:free)` مشخص شده‌اند — هزینه‌ای ندارند

### گزینه ۲ — DeepSeek (پولی، ارزان)
1. به [platform.deepseek.com](https://platform.deepseek.com) بروید
2. ثبت‌نام کنید و حساب را شارژ کنید (نیاز به اعتبار اولیه دارد — رایگان نیست)
3. از بخش **API Keys** کلید بسازید
4. هزینه: حدود ۰.۱۴ دلار به ازای هر ۱ میلیون توکن ورودی و ۰.۲۸ دلار برای هر ۱ میلیون توکن خروجی (قیمت‌ها ممکن است تغییر کنند — قبل از استفاده در [صفحه قیمت‌گذاری رسمی](https://api-docs.deepseek.com/quick_start/pricing) بررسی کنید)

---

## تنظیمات

به **نویسنده هوشمند ← تنظیمات API** بروید:

1. سرویس را انتخاب کنید (OpenRouter یا DeepSeek)
2. کلید API را وارد کنید
3. مدل را انتخاب کنید
4. روی **تست اتصال** کلیک کنید
5. ذخیره کنید

---

## استفاده

به **نویسنده هوشمند ← تولید محتوا** بروید:

1. **کلمه کلیدی** وارد کنید (مثال: `درمان اضطراب اجتماعی`)
2. **عنوان مقاله** وارد کنید (مثال: `درمان اختلال اضطراب اجتماعی با CBT`)
3. **وضعیت انتشار** انتخاب کنید (پیش‌نویس توصیه می‌شود)
4. روی **تولید مقاله** کلیک کنید
5. بعد از ۳۰-۹۰ ثانیه مقاله آماده و ذخیره می‌شود

---

## ویژگی‌های امنیتی

- تمام ورودی‌ها sanitize می‌شوند
- نonce verification برای تمام AJAX requests
- بررسی سطح دسترسی کاربر
- کلیدهای API در دیتابیس وردپرس ذخیره می‌شوند (مانند سایر تنظیمات افزونه‌ها) — رمزنگاری اضافه ندارند، پس مطمئن شوید دسترسی به دیتابیس و wp-admin سایت محدود است
