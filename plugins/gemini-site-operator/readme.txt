اپراتور هوشمند و ناظر دائمی وردپرس: ممیزی کل سایت، صف اولویت‌بندی، اصلاح امن با Snapshot و Rollback، تولید محتوا/متا/Alt/CSS و پایش رویدادمحور — مستقیم با Gemini API و کلید شخصی.

== Description ==

این افزونه یک «اپراتور ناظر» برای کل سایت وردپرس است و چهار حلقه را به هم وصل می‌کند: کشف نواقص، اولویت‌بندی، اصلاح قابل بازگشت، و پایش آینده.

**۱) موتور ممیزی کل سایت (دسته‌ای و بدون Timeout)**
* ساختار محتوا: نبود/چند H1، پرش سطح هدینگ، محتوای کم‌حجم، نبود CTA
* سئو و رسانه: نبود/طول نامناسب عنوان و توضیحات متا، نبود اسکیما، تصاویر بدون Alt (رسانه و درون‌محتوا)، لینک شکسته داخلی/خارجی
* فروشگاه (در صورت فعال بودن ووکامرس): نبود/کم‌حجمی توضیحات کامل و توضیح کوتاه، تصویر شاخص و گالری، Alt تصاویر محصول، قیمت و وضعیت موجودی محصول و تنوع‌ها، دسته‌بندی و برچسب، و یکنواختی ساختار معرفی
* سئو پیشرفته: تشخیص عنوان/توضیح متای تکراری و محتوای هم‌پوشان، نبود لینک داخلی، و پشتیبانی از Yoast، Rank Math، AIOSEO و SEOPress
* فنی: WP_DEBUG فعال، حجم debug.log، پیوند یکتای ساده، شورت‌کد بدون هندلر، شناسه HTML تکراری
* دسته/برچسب بدون توضیح و آیتم شکسته منو

اسکن در دسته‌های کوچک روی WP-Cron اجرا می‌شود؛ هر تیک فقط `batch_size` آیتم را می‌بیند تا هاست دچار ۵۰۴ یا Memory Limit نشود.

**۲) صف اولویت‌بندی و اصلاح**
هر ایراد در چهار سطح بحرانی/مهم/متوسط/بهینه‌سازی ثبت می‌شود. اصلاح تکی با پیش‌نمایش قبل/بعد و Diff، یا اصلاح دسته‌ای در پس‌زمینه. قبل از هر تغییر یک Snapshot از محتوا، متاها، Alt، ترم یا تنظیمات ثبت می‌شود و با یک کلیک بازگشت دقیق انجام می‌گیرد.

**۳) ابزارهای تولید**
* تولید محتوای تازه (HTML تمیز، بدون H1، همراه متا و خلاصه)
* بازنویسی صفحه موجود با پیش‌نمایش و اعمال تأییدشده
* تولید عنوان/توضیحات متا، Alt تصاویر، خلاصه نوشته، توضیح دسته
* پیشنهاد لینک داخلی از میان مقصدهای واقعی سایت (بدون URL ساختگی)
* ویرایش CSS سفارشی با هشدار امنیتی، پاک‌سازی و Snapshot

**۴) پایش دائمی**
هوک‌های `save_post`، `transition_post_status`، `add_attachment`، `edit_attachment`، `edited_term`/`created_term` و هوک‌های محصول ووکامرس یک صف کوتاه می‌سازند. اسکن دوره‌ای ساعتی/روزانه/هفتگی قابل تنظیم است. سه حالت خودکارسازی: فقط گزارش، اصلاح خودکار کم‌ریسک (Alt و متا)، و پیشنهاد خودکار + تأیید دستی برای تغییرات محتوایی/کدی.

**امنیت و حریم داده**
* کلید API فقط سمت سرور و با `wp_remote_post` استفاده می‌شود؛ در فرانت‌اند یا URL ظاهر نمی‌شود.
* کلید در دیتابیس با AES-256 و salt وردپرس رمزنگاری می‌شود (در نبود OpenSSL با برچسب هشدار).
* همه فرم‌ها nonce دارند، همه AJAXها `check_ajax_referer` و `current_user_can('manage_options')`، ورودی‌ها با `sanitize_*` و خروجی‌ها با `esc_*`.
* محدودیت نرخ دقیقه‌ای + فاصله بین درخواست‌ها + تلاش مجدد کنترل‌شده برای خطاهای ۴۲۹/۵xx.

== Installation ==

1. پوشه `gemini-site-operator` را در `wp-content/plugins/` قرار دهید (یا zip را از پیشخوان نصب کنید).
2. افزونه را فعال کنید؛ چهار جدول `wp_gso_*` ساخته و کران‌ها زمان‌بندی می‌شوند.
3. از «Gemini Operator → تنظیمات» کلید Gemini API را وارد کنید (کلید از Google AI Studio).
4. مدل‌ها را انتخاب کنید: مدل Flash برای اسکن/متا/Alt و مدل Pro برای بازنویسی و کد.
5. از داشبورد «شروع اسکن کل سایت» را بزنید و سپس از «صف اصلاح» از بحرانی‌ترین مورد شروع کنید.

== Frequently Asked Questions ==

= آیا بدون کلید API هم کار می‌کند؟ =
بله. همه بررسی‌های ساختاری، سئو، تصویر، لینک و ووکامرس محلی هستند. کلید فقط برای تولید متا، Alt، بازنویسی و CSS لازم است.

= اسکن روی هاست اشتراکی سنگین نیست؟ =
خیر. هر تیک کران حداکثر «اندازه دسته اسکن» آیتم را پردازش می‌کند (پیش‌فرض ۱۰) و بررسی لینک‌ها با کش هفت‌روزه و سقف قابل تنظیم انجام می‌شود.

= اگر اصلاحی را نپسندم چه می‌شود؟ =
از دکمه «بازگردانی» در همان ردیف پیش‌نمایش یا صفحه گزارش‌ها استفاده کنید؛ Snapshot وضعیت قبلی را دقیق برمی‌گرداند و ایراد دوباره باز می‌شود.

= آیا قیمت محصول یا محتوای حساس را خودکار تغییر می‌دهد؟ =
قیمت هرگز حدس زده نمی‌شود و فقط به‌صورت «نیازمند اقدام دستی» گزارش می‌شود. تغییرات محتوایی در حالت «پیشنهاد + تأیید» فقط پس از تأیید اپراتور اعمال می‌شوند.
