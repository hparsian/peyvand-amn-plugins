# Piwand Daily Feed — راهنمای نصب و استفاده

## نصب

1. فایل زیپ را از طریق **پیشخوان ← افزونه‌ها ← افزودن** آپلود کنید
2. افزونه را فعال کنید
3. از منوی **کارت‌های روزانه** در پیشخوان استفاده کنید

---

## ایجاد کارت

1. **کارت‌های روزانه ← افزودن کارت**
2. عنوان (اختیاری) و محتوا را بنویسید
3. از باکس کناری «تنظیمات کارت»:
   - نوع محتوا را انتخاب کنید (متن / نقل‌قول / تصویر / تمرین / سوال)
   - رنگ اختصاصی کارت را انتخاب کنید
   - برچسب نویسنده/منبع بنویسید
   - در صورت تمایل کارت را پین کنید
4. انتشار دهید

---

## نمایش در سایت

### روش ۱ — شورت‌کد
در هر صفحه یا پست بنویسید:
```
[piwand_feed]
```

### روش ۲ — ویجت
از **ظاهر ← ابزارک‌ها** ویجت «پیوند امن — فید روزانه» را به sidebar یا footer اضافه کنید.

### روش ۳ — کد PHP (در template)
```php
echo do_shortcode('[piwand_feed]');
```

## تنظیمات

از منوی **کارت‌های روزانه ← ⚙️ تنظیمات** می‌توانید تغییر دهید:

| تب | گزینه‌ها |
|---|---|
| 🖥️ نمایش | حالت (اسلایدر/فید/گرید/ماسونری)، تعداد کارت، ترتیب، بازه زمانی |
| ✨ انیمیشن | نوع ورود کارت‌ها، پخش خودکار، سرعت |
| 🎨 رنگ‌بندی | رنگ پیش‌فرض هر نوع محتوا |
| 🧩 المان‌ها | سایه، تاریخ، نوع، نویسنده، دکمه‌ها |

## نکات فنی

- **فونت فارسی**: از Vazirmatn استفاده می‌کند (از Google Fonts بارگذاری می‌شود)
- **RTL**: کاملاً راست‌به‌چپ
- **موبایل**: ریسپانسیو — در موبایل swipe روی اسلایدر کار می‌کند
- **تاریخ شمسی**: اگر افزونه jDatetime نصب باشد تاریخ شمسی نمایش می‌دهد
- **امنیت**: همه خروجی‌ها escape شده، nonce بر روی AJAX

### سازگاری با Page Builder ها
اگه shortcode رو داخل Elementor، Divi یا ACF استفاده می‌کنی، `has_shortcode` کار نمی‌کنه.
این کد رو به `functions.php` قالبت اضافه کن:
```php
add_filter( 'pwdf_force_enqueue', '__return_true' );
```
