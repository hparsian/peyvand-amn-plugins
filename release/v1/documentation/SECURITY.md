# الزامات امنیتی — اکوسیستم پیوند امن v1

## ۱. مدل هویت و دسترسی

| موجودیت | شناسهٔ کلید | نحوهٔ دسترسی |
|---|---|---|
| مراجع | شمارهٔ موبایل (`phone` / متای `zdp_mobile`) | فقط به دادهٔ خودش، از طریق نشست پنل |
| درمانگر | کاربر وردپرس با نقش `pas_cf_therapist` | فقط پرونده‌های تخصیص‌یافته (`assigned_therapist`) |
| سرپرست | `pas_view_all_case_files` / `manage_options` | همهٔ پرونده‌ها |
| مدیر | `manage_options` | همهٔ داده‌ها و تنظیمات |

**قاعدهٔ ثابت:** شمارهٔ موبایل شناسهٔ حساس است. هیچ endpointی نباید شمارهٔ مراجع را از
پارامتر درخواست بگیرد و دادهٔ او را برگرداند؛ منبع شماره در پنل، همیشه نشست/متای کاربر
وارد‌شده است.

### ماتریس آزمون‌شده (روی Staging)

| درخواست | نتیجه |
|---|---|
| مهمان → `GET /wp-json/psy/v1/report/1` | `401 rest_forbidden` |
| مهمان → `GET /wp-json/zdp/v1/panel-state` | `403 zdp_rest_forbidden` |
| مهمان → `POST /wp-json/zdp/v1/send-otp` | `403` |
| مشترک (subscriber) → صفحهٔ گزارش آزمون | `403` |
| درمانگر → صفحهٔ گزارش آزمون | `403` |
| درمانگر A → پروندهٔ درمانگر B | صفحهٔ «شما تخصیص داده نشده است»، بدون افشای داده |
| مراجع وارد‌شده → پنل | فقط دادهٔ خودش؛ شمارهٔ سایر مراجع در HTML نیست |

## ۲. رمزنگاری

- الگوریتم در `Pas_Core_Crypto` متمرکز است؛ پیشوند داده‌های رمزشده `enc1:`.
- کلید از `PAS_CORE_ENCRYPTION_KEY` یا `wp-content/pas-encryption-key.php`.
- سکرت 2FA با کلید مشترک رمز می‌شود؛ کدهای پشتیبان **هش‌شده** ذخیره می‌شوند.
- تعویض/بازتولید کلید ممنوع: داده‌های موجود ناخوانا می‌شوند.
- مقدار کلید هرگز در گزارش، لاگ، ZIP یا Git نوشته نمی‌شود.

## ۳. کنترل‌های موجود

| کنترل | پیاده‌سازی |
|---|---|
| CSRF | `check_admin_referer` / `check_ajax_referer` در ۲۴ فایل، ۹۰+ نقطهٔ بررسی |
| Nonce پنل و REST | `wp_verify_nonce` + `X-WP-Nonce` در مسیرهای احراز‌شده |
| SQL | Prepared statement؛ هیچ کوئری با درج مستقیم `$_GET/$POST` یافت نشد |
| XSS | خروجی با `esc_html/esc_attr/esc_url/wp_kses_post` |
| Rate limit OTP | شمارندهٔ transient + `GET_LOCK` برای جلوگیری از race |
| Rate limit 2FA | شمارندهٔ تلاش + قفل پس از `MAX_ATTEMPTS` |
| آپلود فایل | محدود به نوع‌های مجاز در فرم‌های پرونده (بدون اجرای PHP) |
| دسترسی مستقیم فایل | `if (!defined('ABSPATH')) exit;` در همهٔ فایل‌های include |

## ۴. چک‌لیست پیش از انتشار

- [ ] `PAS_CORE_ENCRYPTION_KEY` در Production ست و همان کلید قبلی است
- [ ] 2FA برای همهٔ حساب‌های `administrator` فعال و کدهای پشتیبان در جای امن
- [ ] صفحهٔ پنل مراجع فقط از طریق صفحهٔ تعیین‌شده باز می‌شود
- [ ] دسترسی `wp-content/pas-encryption-key.php` روی وب‌سرور بسته است (`chmod 600`، deny در nginx/apache)
- [ ] لاگ‌ها بدون شمارهٔ کامل موبایل و بدون متن پیامک
- [ ] درگاه پرداخت با کلید Production و بازگشت به HTTPS
