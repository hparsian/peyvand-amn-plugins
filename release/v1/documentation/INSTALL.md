# نصب از صفر — اکوسیستم پیوند امن v1

این سند نصب کامل ۱۱ افزونهٔ «پیوند امن» را روی یک وردپرس تازه توضیح می‌دهد.
نسخه‌های تأییدشده: **WordPress 7.1.4** و **PHP 8.5.8** (حداقل اعلام‌شده: WordPress 6.6، PHP 8.1).

---

## ۰. پیش‌نیازها

| مورد | مقدار لازم |
|---|---|
| WordPress | 6.6 یا بالاتر (تأییدشده روی 7.1.4) |
| PHP | 8.1 یا بالاتر (تأییدشده روی 8.5.8) |
| MySQL / MariaDB | 5.7 / 10.4 یا بالاتر، `utf8mb4` |
| افزونهٔ رمزنگاری | `openssl` یا `sodium` در PHP فعال باشد |
| دسترسی | `manage_options` برای نصب و پیکربندی |

قبل از شروع یک بکاپ کامل بگیرید (بخش «بکاپ پیش از نصب»).

---

## ۱. ترتیب نصب

ترتیب زیر از وابستگی واقعی کد استخراج شده است؛ رعایت آن الزامی است:

1. `pivand-amn-core` (اجباری برای همه)
2. `pivand-amn-sms-bridge`
3. `pivand-amn-smtp-mailer`
4. `pivand-amn-2fa`
5. `pivand-amn-case-file`
6. `pivand-amn-quiz-enterprise`
7. `pivand-amn-client-portal`
8. `payvand-amn-ui-kit`
9. `payvand-contact`
10. `pivand-amn-content-writer`
11. `piwand-daily-feed`

نصب هر افزونه: **افزونه‌ها → افزودن → بارگذاری افزونه** و انتخاب فایل ZIP از پوشهٔ `plugins/`.
نام پوشهٔ داخلی هر ZIP دقیقاً برابر اسلاگ افزونه است؛ ZIP را دستکاری یا بازنام‌گذاری نکنید.

> هیچ‌گاه دو افزونهٔ پیامک را هم‌زمان فعال نکنید. تنها ارائه‌دهندهٔ قرارداد `pas_send_sms` در این بسته `pivand-amn-sms-bridge` است.

## ۲. کلید رمزنگاری (حیاتی)

داده‌های حساس (پاسخ‌های آزمون، تاریخچهٔ بالینی، سکرت 2FA) با `Pas_Core_Crypto` رمز می‌شوند.
کلید از یکی از دو منبع خوانده می‌شود، به همین ترتیب:

1. ثابت `PAS_CORE_ENCRYPTION_KEY` در `wp-config.php`
2. فایل `wp-content/pas-encryption-key.php`

قواعد:

- کلید **هرگز** داخل ZIP، Git یا گزارش قرار نمی‌گیرد.
- اگر سایت قبلاً داده دارد، **همان کلید قبلی** باید باقی بماند؛ تعویض کلید داده‌های موجود را ناخوانا می‌کند.
- اگر کلید موجود نیست، انتشار را متوقف کنید و ابتدا کلید را بازیابی کنید.

بررسی سلامت: در ابزار سلامت سایت، بخش «پیوند امن» باید وضعیت رمزنگاری را «فعال» نشان دهد؛ در غیر این صورت هیچ آزمونی را شروع نکنید.

## ۳. پیکربندی پس از نصب

| افزونه | کار لازم |
|---|---|
| core | ثبت تنظیمات پایه و بررسی سلامت رمزنگاری |
| sms-bridge | وارد کردن کلید پنل پیامک و شمارهٔ فرستنده، سپس ارسال پیامک آزمایشی |
| smtp-mailer | وارد کردن میزبان/پورت/کاربر SMTP و ارسال ایمیل آزمایشی |
| 2fa | فعال‌سازی برای حساب مدیر و ذخیرهٔ کدهای پشتیبان در جای امن |
| case-file | تعیین درمانگران و تخصیص پرونده‌ها |
| quiz-enterprise | بررسی وجود ۲۸ آزمون در صفحهٔ آزمون‌ها |
| client-portal | تعیین صفحهٔ پنل مراجع و اتصال درگاه پرداخت (در صورت نیاز) |
| ui-kit | بدون تنظیمات؛ فقط ظاهر |
| payvand-contact | ساخت صفحهٔ فرم تماس |
| content-writer | وارد کردن کلید API در صورت استفاده از تولید محتوا |
| daily-feed | بررسی فعال بودن cron وردپرس |

## ۴. آزمون پذیرش نصب

1. `wp plugin list` → هر ۱۱ افزونه `active` و نسخه‌ها برابر مانیفست.
2. صفحهٔ اصلی و پیشخوان بدون خطای PHP باز شوند.
3. یک آزمون آزمایشی کامل بدهید و گزارش آن را ببینید.
4. یک پروندهٔ آزمایشی بسازید و در پنل درمانگر ببینید.
5. رمزنگاری: دادهٔ آزمون پس از ذخیره قابل خواندن باشد (نه رشتهٔ خام).

## ۵. بکاپ پیش از نصب

```
# دیتابیس
mariadb-dump --single-transaction --default-character-set=utf8mb4 \
  -h<host> -u<user> -p <db> | gzip -c > backup-db-$(date +%F).sql.gz

# فایل‌ها
tar -czf backup-wpcontent-$(date +%F).tar.gz -C wp-content .
```

بکاپ دیتابیس را هرگز در مخزن Git یا کنار فایل‌های وب قرار ندهید.
